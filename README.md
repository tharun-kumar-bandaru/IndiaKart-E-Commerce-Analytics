# 🇮🇳 IndiaKart E-Commerce Analytics

##  Internship Project

This project was developed as part of my **Data Analytics Internship at Internmo**.

The **IndiaKart E-Commerce Analytics Project** focuses on analyzing e-commerce data across customers, orders, products, payments, inventory, and returns to identify meaningful business insights and support data-driven decision-making.

> **Organization:** Internmo
> **Project:** IndiaKart E-Commerce Analytics Project
> **Role:** Data Analytics Intern
> **Project Status:** In Progress

---

##  Project Objective

The objective of this project is to perform an end-to-end data analytics workflow on IndiaKart's e-commerce datasets.

The project focuses on:

* Understanding the available datasets
* Assessing data quality
* Cleaning and preparing the data
* Performing exploratory data analysis
* Analyzing sales and customer behavior
* Studying product and inventory performance
* Analyzing payments and returns
* Developing business insights
* Creating interactive Power BI dashboards

#  Phase 1 — Data Understanding & Quality Analysis

The first phase focuses on understanding the structure, content, and quality of the IndiaKart datasets.

The analysis includes:

* Dataset dimensions
* Number of rows and columns
* Data types
* Missing-value analysis
* Duplicate-record analysis
* Primary-key identification
* Foreign-key identification
* Relationship analysis
* Invalid-value detection
* Data consistency checks

---

#  Phase 2 — Data Cleaning

The data-cleaning process includes:

* Handling missing values
* Removing duplicate records where appropriate
* Correcting data types
* Converting date columns
* Checking numerical values
* Standardizing categorical values
* Validating relationships between datasets

---

Python and Pandas are used to explore the data and identify patterns.

Key areas include:
